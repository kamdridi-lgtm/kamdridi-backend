## Principle
Digital = discovery engine. Physical = monetization / proof / retail engine.
Physical is not decoration: KAM DRIDI wants real CD sales in DACH.
Every path below requires zero big cash upfront from the artist.

All figures marked (est.) are market estimates, not quotes. No contacts invented.

## PATH A — Distributor / label finances the first run (P&D or licensing)

The partner presses, stocks, sells. The artist risks nothing but terms.

| Dimension | Value |
|---|---|
| Cash required (artist) | 0 € |
| Margin | Licensing: target 50/50 net (floor 40% artist) — market usage, validate with lawyer. P&D: royalty per unit or net share after recoupment |
| PPD / wholesale | RRP 15,99 € → PPD ~8,00–8,50 € (est.) → distributor commission 20–25% → net label ~6,00–6,80 €/unit (est.) |
| Stock | 500–1 000 units first run, held and managed by partner |
| Returns | Risk on the licensee (non-negotiable deal term). Firm sale preferred; no sale-or-return for an unknown artist |
| Timelines | 6–8 weeks production after deal signature |
| Control | Medium-low: partner controls manufacturing, retail pitch, replenishment |
| Risk | Low cash risk. Main risk = bad terms lock-in (mitigated by: 2–3 yr term max, DACH only, no tacit renewal, written reporting, exit triggers) |
| GO | Deal meets the non-negotiable terms + partner does real retailer solicitation (not just orderability) + back catalogue included |
| NO-GO | Mandatory PR fee as distribution condition / worldwide exclusivity >3 yrs without minimums / no written reporting / artist asked to fund any part of the pressing |

## PATH B — Consignment / micro-run funded by preorders / retailer POs

A small run exists only because demand already paid for it. No speculation.

| Dimension | Value |
|---|---|
| Cash required (artist) | ~0 € net (preorders/POs fund the run before pressing) |
| Margin | Higher per unit (no distributor cut), smaller volume. Indicative: 300 units × ~2,50 €/unit (short-run premium, est.) = ~750 € cost → ~50 preorders at 15,99 € = ~800 € revenue. Tight by design |
| PPD / wholesale | Direct-to-retail consignment: retailer keeps ~40–50% of RRP (est.). Direct-to-fan: full RRP minus shipping/fees |
| Stock | 200–300 units micro-run. Held by artist or consigned to 2–3 indie retailers |
| Returns | Consignment = unsold units come back. Acceptable at this scale; remainder becomes tour merch |
| Timelines | 2–3 weeks preorder window + 3–4 weeks short-run production = 5–7 weeks total |
| Control | High: artist decides quantity, price, allocation |
| Risk | Low cash (pre-funded). Operational risk = fulfillment burden (packing/shipping) — must be assigned to an operator, never to Karim as a task |
| GO | Preorder threshold met (≥150 preorders) OR retailer POs ≥200 units OR confirmed tour inventory need |
| NO-GO | Threshold not met → DO NOT PRESS. Discipline is the product |

## PATH C — Print-on-demand / short-run, no heavy stock

The permanent floor: the album is always buyable physically, everywhere, at zero risk.

| Dimension | Value |
|---|---|
| Cash required (artist) | 0 € (made to order) |
| Margin | Lowest per unit. Indicative POD CD cost ~5–8 €/unit (est., provider-dependent) → at 15,99 € RRP, margin ~8–11 €/unit before fees, but no volume |
| PPD / wholesale | N/A — direct-to-fan only, no wholesale channel |
| Stock | Zero |
| Returns | Zero (made to order) |
| Timelines | 1–2 weeks per order, provider-dependent |
| Control | Full |
| Risk | Near zero cash. Strategic risk = perceived as "not a real release" by retail (no shelf presence = no proof/retail engine) |
| GO | Always, as the floor — from release day, no matter what |
| NO-GO | As the PRIMARY DACH strategy — it delivers no retail proof |
