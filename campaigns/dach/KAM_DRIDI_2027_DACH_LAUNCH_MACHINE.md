# KAM DRIDI — 2027 DACH / EUROPE LAUNCH MACHINE
Prepared: 2026-10-19
Status: ACTIVE WORKING PLAN

## Mission
Build a repeatable release-and-distribution system for KAM DRIDI that does not depend on expensive bundled PR packages.

Core commercial story:
- ECHOES UNEARTHED = Album #1 / 2026 / back catalogue.
- TWICE UPON A TIME = Album #2 / 2027 / active release campaign.
- 2027 touring in Japan, Australia and New Zealand supplies proof, content and international narrative.
- Europe / DACH is treated as a physical-sales and market-development operation, not just digital availability.

## 1. Release architecture
1. Select one lead single from TWICE UPON A TIME.
2. Build DACH promo around the new single, not a recycled 2026 narrative.
3. Open physical preorders / retailer onboarding for TWICE UPON A TIME.
4. Add ECHOES UNEARTHED as back catalogue in the same physical network.
5. Use tour activity, radio proof and new media as the credibility layer.
6. Launch album with a second radio / press push and retailer re-order cycle.
7. Keep digital distribution independent unless a partner offers measurable strategic value.

## 3. GO / NO-GO rules for any distributor or label
A deal is GO only if most of the following are true:
- Real physical distribution in Germany, Austria and Switzerland.
- Clear retailer / mail-order / e-tailer servicing.
- Explicit stock intake, warehousing and replenishment process.
- Transparent returns policy and stock accounting.
- No mandatory EUR 2,950+ PR package as a condition of basic distribution.
- Defined commission / royalty basis.
- Defined territory and term.
- No unnecessary worldwide exclusivity.
- New album and back catalogue can coexist.
- Reporting schedule is written.
- Physical placement is more than theoretical orderability.

Automatic NO-GO triggers:
- Multi-year exclusivity covering unrelated future catalogue without meaningful investment.
- Mandatory high-cost promo with vague outputs.
- No physical stock handling.
- No retailer solicitation or wholesale route.
- No written reporting / accounting terms.
- “Guaranteed charts” or traffic promises that cannot be explained compliantly.

## 5. Physical economics to build
Working model to validate with distributors:
- Initial manufacturing run should be demand-led, not prestige-led.
- Start with a controlled first batch suitable for wholesale, direct sales and touring.
- Distributor must state:
  - first stock intake,
  - wholesale price / PPD,
  - retailer margin,
  - distributor commission,
  - storage fees,
  - pick/pack fees,
  - returns charge,
  - reorder threshold,
  - payment schedule.

Decision principle:
No large pressing until one of these exists:
1. retailer / distributor intake commitment,
2. proven preorder demand,
3. tour inventory need,
4. cost curve justifies a larger run.
